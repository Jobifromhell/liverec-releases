# LiveRec

Multitrack recorder for live shows, working hand in hand with [Patcher](https://patcher.fr).

This repository only hosts the installers. Download the latest version:

- **macOS** (13 or later, Apple silicon and Intel): [LiveRec-mac.dmg](https://github.com/Jobifromhell/liverec-releases/releases/latest/download/LiveRec-mac.dmg)
- **Windows** (10 or later, 64-bit): [LiveRec-windows.zip](https://github.com/Jobifromhell/liverec-releases/releases/latest/download/LiveRec-windows.zip)

All versions: [Releases](https://github.com/Jobifromhell/liverec-releases/releases).

LiveRec needs a Patcher account (free): sign in with the one you use on patcher.fr, or create it from LiveRec.
